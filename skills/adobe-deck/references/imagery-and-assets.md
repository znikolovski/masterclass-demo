# Adobe Deck — Imagery and Assets

Load this reference when the deck includes imagery, screenshots, icons, product logos, external logos, or animation.

---

## Imagery Principles

All imagery must come from **Adobe Stock** or **Adobe Firefly** only. Never use images from other sources.

**Select images that are:**
- Bold, bright, and colourful
- Show movement and depth
- Have a singular focal point or an unexpected point of view
- Representative of diversity when depicting people (consider skin tones and cultural references)

**Do not use:**
- Photography that feels obviously staged, forced, overly styled, or clip-art style
- Text-fill style images
- Black and white photography
- Images with an overly dark or muted colour palette
- Imagery from any source besides Adobe Stock or Adobe Firefly

---

## Adobe Firefly Guidance

**External-facing presentations:** Use only the pre-approved set of generated abstract textures available on Brand Center. Do not generate your own for external audiences.

**Internal presentations:** Generate colourful abstract textural elements similar to the Brand Center set.

**Best Firefly settings:**
- Content type: Photo
- Movements: None, baroque, cyberpunk, fantasy, psychedelic
- Themes: None, optical illusion
- Techniques, Effects, Materials: None (or 3D patterns for Materials)
- Concepts: None, chaotic

**Do not generate photographic humans in Firefly** — use Adobe Stock for any imagery depicting real people.

## Screenshots

- Screenshots must be clear, focused, and attractive
- Fill the content area with an interesting image or useful data — minimise dead space; crop out anything not needed
- **Login:** Always be logged in to any website being screenshotted
- **File names:** Save files with a clear benign name (e.g. `Spring Collection Q3.psd`, not `Untitled-1.psd`)
- **Browser hygiene:** Only one tab open; no bookmark bar; no personal plugins or extensions. Use a clean browser profile (Firefox, Safari, Brave, or Edge) specifically for screenshots. Use a window resizer extension to set correct device dimensions.
- Capture the window only (not the OS UI) unless showing multiple apps open is the point

---

## Device Shells

Used to frame screenshots. Use only official Adobe device shells.

| Shell | Background | When to use |
|-------|-----------|-------------|
| Light gray shell | White | Preferred for most use |
| Dark gray shell | Black | Preferred for dark slides |
| White shell | Special cases only | Only when the device cannot go on white or black; avoid if possible |

- **Never recolour the shells**
- Match shell type to screenshot type (smartphone shell = smartphone screenshot)
- Resize by holding Shift and dragging from a corner (maintain proportions)
- Format and crop the screenshot to fit the shell — do not distort the shell
- Shells provide very little contrast against the background so the screenshot stands out

---

## Icons

- Use only the approved Adobe icon set from Brand Center
- Icons: black on white background, or white on black background only — **never recoloured**
- **Do not** make your own icons
- **Do not** mix Adobe icons with PowerPoint built-ins or internet sources
- Maximum icon size: 1.5" × 1.5" in PowerPoint, or 200 × 200px in Keynote
- Do not distort or modify icons in any way

---

## Product Logos (Adobe)

- Best placement: white or black background with sufficient space around them to stand alone
- If a product needs a label, use an editable text box in Adobe Clean Regular — not a pre-made lockup image
- **Never** obscure, stack, recolor, outline, make substitutes for, or otherwise modify Adobe product logos
- Available from Brand Center in horizontal and vertical layout variants
- "Lockups" (icon + text bundled as an image) are no longer used

---

## External Company Logos

- Treat with the same respect as Adobe logos — never modify or distort
- Always use the most current primary version of the logo sourced from the company's website or a direct contact there
- For multiple logos: grid layout, consistent visual weight (look away then look back — if one jumps out, shrink it)
- Alphabetise or order by importance
- Use Align and Distribute tools for even spacing
- Place on a white field whenever possible to avoid needing transparent versions

---

## Animation

Animation should be **subtle and deliberate** — never gratuitous or distracting.

| Transition | Duration | When to use |
|-----------|---------|-------------|
| Fade | 0.7 sec | Default for most slides |
| Morph | ~2 sec (adjust to feel) | When elements need to reposition/rescale between slides |
| None | — | When streaming or presenting in environments where animation stutters |

**For builds and object animations:**
- Use Fade as the default
- Appear or other subtle animations only when integral to illustrating a process
- Animation must make sense in context — never use it just because it's available

**Goal:** slides transition smoothly without calling attention to the animation itself.
