# Adobe Deck — Slide Anatomy

## Required Deck Shell

| Position | Slide type | Required |
|----------|-----------|----------|
| First | Title slide | Yes — always first |
| Second (optional) | Agenda | Recommended for multi-section decks |
| Per section | Section divider | One per major section |
| — | Content slides | Body of the deck |
| Last | Closer slide | Yes — always last (red Adobe wordmark version) |

Multiple speakers: one title slide per speaker. Only one closer slide at the very end of the entire presentation.

---

## Title Slide

### Preferred variant: Red (no imagery)
- Full red (`#EB1000`) background
- **Presentation title:** Adobe Clean Display Black, large, left-justified, sentence case
- **Speaker name + title:** `Speaker Name  |  Speaker Title` — Display Black, 20pt
- This is the standard; use it unless a specific theme calls for imagery

### Alternative variant: 50/50 image layout
- Image on the right half of the slide; title/speaker info on the left
- Use to distinguish between different speakers in a multi-speaker deck, or to give a deck a lively feel
- Use full-bleed image variants from the title slide library (Firefly-generated or Adobe Creative Residency artist images)
- Image credit line: small text, e.g. `Image generated with Adobe Firefly` or artist attribution

### Rules
- Never use a plain white background for the title slide — red or 50/50 image only
- Speaker name and title separated by pipe on no-image slides; separate lines (no pipe) on image slides if needed
- The A-pattern from previous templates is retired — do not use it

### Note — Rebecca's preference
Red title slide is acceptable. For image variants, use those with predominantly light/white areas rather than dark or charcoal full-slide backgrounds.

---

## Section Dividers

- Stark black or white — no imagery, no colour other than the red thread and wordmark
- Short title only; designed to be on screen for only a few seconds as a visual palette cleanser
- Make it easy to locate sections in Slide Sorter view
- Title format: `Section number  |  Section title` where appropriate
- Available variants: standard (white), dark — **Rebecca's preference: use white/light variant**

---

## Agenda Slide

Three variants:
- **Presentable version:** Speaker / Section / Time columns in a clean table. Live presentation use only.
- **Handout version:** Adds descriptive intro text block above the table. Never present live.
- **Agenda + Image:** Adds a supporting image alongside the table.

Table setup:
- Header row: Adobe Clean Display Black / Bold
- Cell text: left-aligned horizontally, vertically centred
- Borders: inside horizontal only, 0.5pt dark gray pen. No outer borders, no vertical borders.
- Rows and columns evenly distributed (Table Layout > Distribute tools)
- Only shade rows that need emphasis

---

## Content Slides

### Presented version
- Keep all content within the content area guides
- Visual element required on every slide (image, icon, chart, diagram, or shape)
- Max 5 bullets × 6–7 words
- 2020 "airy" layout: larger title, smaller content area, generous line spacing — preferred for new slides
- Leave white space; the template is deliberately more constrained than legacy versions

### Handout version
- More detail acceptable
- Pipe in title: `Slide Title  |  Detailed Version`
- Still avoid 3rd-level bullets

### Dark content slide
- Available for image-heavy sections
- Rebecca's preference: use white/light variants

### Deck flow guidance
- Text-heavy presentations work better on white backgrounds
- Image-heavy presentations work better on dark backgrounds (use light per Rebecca's preference)
- Alternate light/dark strategically — dark section dividers before white content slides create a sense of new topic

---

## Closer Slide

- **Always the last slide** — do not end on a content or data slide
- Must be the red Adobe wordmark closer slide
- This is a visual cue to the audience that the entire presentation is complete
- Do not place a closer slide after each speaker section — one closer at the very end only

## Common Content Layout Types (see layout-library.md for full patterns)

| Layout | Use case |
|--------|----------|
| Title + bullets (airy) | General content, key points |
| Full-bleed image + 3–4 words | Big idea, conceptual statement |
| 50/50 image + text | Practical information, product features, longer quotes |
| Two-column text | Comparisons, pros/cons |
| Three columns with icons | Feature/capability overviews |
| Stat callout | Single big number or metric |
| Quote slide | Customer/partner endorsements, pithy statements |
| Dashboard | Multiple metrics at a glance |
| Collage / image grid | Photo-heavy content |
| Device mockup | Product screenshots |
| Stack / marketecture diagram | Architecture, hierarchy |
| Flowchart | Process steps |
| Cycle diagram | Cyclical/flywheel concepts |
| Timeline | Events over time, roadmaps |
| Table | Structured two-axis data |
| Org chart | Reporting structures |
